# DSH Tray

这是一个极简的 DeepSeek Harness Windows 托盘程序，为 DeepSeek Harness 提供最基本的 Windows 程序体验，不同于其他厚重的 DeepSeek Harness 桌面客户端。

- 双击 `.exe` 程序或快捷方式直接打开 DeepSeek Harness
- 将 DeepSeek Harness 加入开始菜单 / 开始屏幕
- 在 Windows 托盘显示 DeepSeek Harness 状态
- 在托盘控制 DeepSeek Harness 后端
- 双击图标打开 DeepSeek Harness 前端

如果您的 DeepSeek Harness 启动配置与我不同，您可以让 DSH 为您配置。
